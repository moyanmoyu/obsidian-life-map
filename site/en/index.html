Everything you need

Not just "there is a map" — places treated as real data.

Four data sources

Note frontmatter, GeoJSON, CSV, and any JSON API declared with JSONPath. No code required.

Places, not pins

Notes at the same coordinate merge into one marker; each visit becomes a sub-record you can open or delete.

Three sidebar views

Place list, photo wall and timeline. Click an entry and the map flies to it.

Inline maps

Drop a life-map code block into a note and render a small map in place.

Basemaps that fit

Tianditu with automatic fallback, an AMap tile preset, custom XYZ. Coordinates are converted, so pins line up.

No lock-in

Export the current filtered view to GeoJSON or a Markdown table.

Three steps

  1. InstallDrop three files into .obsidian/plugins/life-map and enable the plugin.
  2. Add coordinatesPut coordinates: ["40.0496", "116.2807"] in frontmatter, or use the "New place note" command.
  3. Open the mapClick the ribbon icon — pins, clustering and the sidebar appear.

Install

Manual (available now)

  1. Download life-map-x.y.z.zip from Releases
  2. Unzip into <your vault>/.obsidian/plugins/life-map/
  3. Obsidian → Settings → Community plugins → enable Life Map

Community directory (in progress)

Once listed you can install it from the community plugin browser.

Requires Obsidian 1.5.0+ · desktop and mobile

Note: the plugin ships without any map key. Tianditu needs your own tk; without it the plugin falls back to a keyless basemap.

FAQ

How is this different from AMap?

You can switch the basemap to AMap tiles, but POI search and routing are not included — those require the AMap JS SDK, which is a different architecture.

Does it work outside China?

Yes. Overseas coordinates skip the GCJ-02 offset automatically and render correctly on OpenFreeMap or any global tile source.

Does it upload my data?

No telemetry. Network access only happens for the basemap you pick and the HTTP sources you configure yourself.

Is deleting a note permanent?

No. Deletes go to the Obsidian/system trash and always require confirmation.
