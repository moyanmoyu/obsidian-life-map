该有的都有

不是"能画个地图"，而是把地点真正当成数据来管理。

四类数据源

笔记 frontmatter、GeoJSON、CSV，以及用 JSONPath 声明的任意 JSON API。不写代码。

按地点聚合

同一坐标的多条笔记合并成一个标记，每次到访作为子记录，可单独打开或删除。

侧栏三视图

地点列表、照片墙、时间轴，点条目地图自动飞过去。

内嵌地图

在笔记里写一个 life-map 代码块，就地渲染小地图。

国内底图

天地图自动降级、高德瓦片预设、自定义 XYZ，坐标系自动转换，点位不错位。

数据不锁死

导出 GeoJSON 或 Markdown 清单，筛选后的结果一键带走。

三步开始

  1. 装插件把三个文件放进 .obsidian/plugins/life-map，在 Obsidian 里启用。
  2. 加坐标笔记 frontmatter 写 coordinates: ["40.0496", "116.2807"]，或者用命令「新建地点笔记」。
  3. 打开地图左侧栏点图标，点位、聚合、侧栏立刻出现。

安装

手动安装（当前可用）

  1. 从 Release 下载 life-map-x.y.z.zip
  2. 解压到 <你的库>/.obsidian/plugins/life-map/
  3. Obsidian → 设置 → 第三方插件 → 启用 Life Map

社区目录

上架后可在「社区插件」里搜索安装，无需手动放文件。

最低 Obsidian 1.5.0 · 桌面端与移动端

常见问题

和高德地图有什么差别？

底图观感可以换成高德瓦片，但拿不到高德的 POI 搜索、路线规划——那些需要高德 JS API，属于另一种架构。

国外地点能显示吗？

能。境外坐标自动跳过 GCJ-02 偏移，底图用 OpenFreeMap 或全球瓦片即可；天地图以中国为主。

会上传我的数据吗？

不会。没有遥测；联网只发生在加载你选择的底图，以及你自己配置的 HTTP 数据源。

删除笔记会永久消失吗？

不会。删除走 Obsidian 的回收站，可恢复；每次删除都有二次确认。
